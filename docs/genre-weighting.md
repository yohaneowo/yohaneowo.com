# 类型环的加权算法

观影页「类型」视图（`src/app/[lang]/moviehub/genre-sunburst.tsx`）是两个独立的环：内环是你的评分段（9+ / 8 / 7 / 6 / <6 / 未评分，同一条由暗到亮的灰阶，亮端是页面的金色），外环是类型。外环的大小不是「含该类型的部数」，而是**按信息量加权**后的和，算法在 `src/app/[lang]/moviehub/genre-weights.ts`。

## 为什么要加权

TMDB 给每部片多个类型，而且顺序没有意义。如果一部片在它的每个类型里各算一部，「剧情」这种半数以上作品都带的标签会吃掉整张图（剧集分页尤其明显：热门剧 62% 带「剧情」）；如果只取第一个类型，又会把《星际穿越》算成「冒险」、《寄生虫》算成「喜剧」。做法借自 Steam 的标签推荐：**标签越常见，信息量越低**；一部片的权重按它所带类型的信息量按比例分配，合计仍是 1。

## 公式

```
share(g)     = 类型 g 在热门作品语料里的出现比例（加一平滑：(count + 1) / (n + 类型数)）
info(g)      = 1 / share(g)，上限为 CAP × info(最常见类型)，CAP = 8
w(film, g)   = info(g) / Σ info(t)      # t 遍历这部片的所有类型，Σ w = 1
sector(g)    = Σ w(film, g)             # 对范围内所有片求和，就是扇区大小
```

- 一部片在扇区的片单里按 `w(film, g)` 由高到低排：《星际穿越》在「科幻」前排、在「剧情」后排。
- 权重和不到范围部数 2% 的类型并入「其他」；没有类型的片也在「其他」。
- 圆心显示范围内的部数；指到某段时显示该段的权重和（四舍五入），浮动提示同时给权重、占比与含该类型的部数。
- 「最常看」也按权重和取最大。
- 语料里没有的类型视为稀有，直接套上限。

上限的用意：尾巴类型（西部、电视电影）在样本里是 1% 还是 2% 差一倍，但 info 一夹到上限就都一样，抓样误差不影响结果。加一平滑则防止某个类型在样本里是 0 或 1 部时权重爆掉。

## 基率怎么来的

三个分页各自一份表，2026-10-18 抓取一次，写成常量；这种比例几年都不会明显变，不随用户自己的观影记录漂移。

| 分页 | 语料                                                     | 样本    | 最常见                                                   | 尾巴                                           |
| ---- | -------------------------------------------------------- | ------- | -------------------------------------------------------- | ---------------------------------------------- |
| 电影 | TMDB `discover/movie`，按热门度，≥ 200 票                | 3000 部 | 剧情 36%、喜剧 32%、动作 31%、惊悚 28%、冒险 26%         | 音乐 1.9%、西部 1.3%、电视电影 0.4%、纪录 0.3% |
| 剧集 | TMDB `discover/tv`，按热门度，≥ 200 票                   | 2591 部 | 剧情 62%、科幻奇幻 36%、喜剧 35%、动作冒险 30%、动画 26% | 真人秀 1.2%、西部 1.0%、脱口秀 0.4%、新闻 0.3% |
| 动漫 | AniList `Page.media(type: ANIME, sort: POPULARITY_DESC)` | 1000 部 | 动作 49%、喜剧 47%、剧情 41%、奇幻 37%、恋爱 35%         | 运动 3.6%、机战 3.1%、音乐 2.4%、魔法少女 0.6% |

表的键用 TMDB / AniList 的英文名；站内的中文类型名经 `src/i18n/genres.ts` 的对照转成英文再查表，动漫分页的类型本来就是 AniList 的英文名。重抓的脚本思路：热门度排序逐页抓、每部片的类型各计一次、加一平滑，电影和剧集抓 3000 部、动漫 1000 部即可（动漫只有 18 个类型，没有长尾）。

## 例子（电影语料）

| 片       | TMDB 类型（比例）               | 分到的权重                      |
| -------- | ------------------------------- | ------------------------------- |
| 星际穿越 | 冒险 0.26、剧情 0.36、科幻 0.12 | 科幻 0.52、冒险 0.31、剧情 0.17 |
| 奥本海默 | 剧情 0.36、历史 0.05、战争 0.04 | 战争 0.49、历史 0.37、剧情 0.14 |
| 霸王别姬 | 剧情                            | 剧情 1.0                        |

数字按上表的比例大致算，实际以 `genre-weights.ts` 里的常量为准。
